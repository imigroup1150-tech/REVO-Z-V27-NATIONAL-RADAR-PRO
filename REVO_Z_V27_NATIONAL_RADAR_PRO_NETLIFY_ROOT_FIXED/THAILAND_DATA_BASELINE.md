# REVO Z National Radar V23 — Thailand data baseline

สถานะข้อมูล: อ้างอิง OSM snapshot/สำนักข้อมูลที่ตรวจสอบได้ ณ 1 ก.ย. 2026 และใช้เป็น baseline สำหรับการออกแบบระบบ ไม่ใช่ตัวเลข “จำนวนจริงทั้งหมดในประเทศ” ของทุกหมวด

## ข้อมูล OSM ระดับประเทศไทยที่ตรวจสอบได้

แหล่งข้อมูล Geo2day แสดง Thailand extract จาก OpenStreetMap ขนาด 353.89 MB และข้อมูล OSM ถึง 30 ส.ค. 2026 23:00 UTC. ตัวเลขที่หน้าเผยแพร่แสดง ได้แก่ police 989 จุด, traffic signals 5,467 จุด, crossing 7,909 จุด, speed camera 27 จุด, schools/kindergartens (polygon) 2,175 แห่ง และถนนประเภท construction 1,134 เส้น. หน้าเดียวกันระบุ amenity points รวม 87,107 จุด และ roads รวม 2,720,717 เส้น แต่สองตัวเลขนี้ไม่ใช่จำนวนหมวดอันตรายโดยตรง

การตีความสำคัญ: speed camera 27 จุดบน OSM ไม่ได้หมายความว่าประเทศไทยมีกล้องจริงเพียง 27 ตัว แต่หมายถึงมีวัตถุที่ติดแท็กตามที่ extract นับได้ใน OSM snapshot นั้นเท่านั้น เช่นเดียวกับสถานีตำรวจ โรงเรียน และสัญญาณไฟ

## หมวดที่ควรใช้ข้อมูลแบบ dynamic

อุบัติเหตุ, รถติด, ทางปิด, น้ำท่วม และรายงานผู้ขับขี่ควรเก็บ timestamp/expiry และระดับความเชื่อมั่น เพราะข้อมูล OSM เหมาะกับโครงสร้างถนน/สถานที่มากกว่าสถานะเหตุการณ์แบบวินาทีต่อวินาที. ระบบ V23 จึงแยก “ข้อมูลจากแผนที่” กับ “รายงานชุมชน” และให้ TTL เฉพาะข้อมูลชั่วคราว

## หมวด static / semi-static ที่เหมาะกับฐานประเทศ

สถานีตำรวจ, สัญญาณไฟ, โรงเรียน, สะพาน, จุดกล้องคงที่, โครงสร้างถนน, จุดทางแคบ/เลนเดียว และทางขึ้นเขา/ลงเขา เหมาะกับการสะสมจาก OSM และแหล่งข้อมูลราชการ แล้ว refresh เป็นรอบยาวกว่าหมวดเหตุการณ์

## หลักการสำคัญของฐานข้อมูล

1. “ค้นไม่พบ” ไม่เท่ากับ “ไม่มีอยู่จริง” จึงต้องมี negative-cache แบบมีอายุและค้นใหม่ได้
2. เปลี่ยนรัศมีให้กรองจากฐานที่มีอยู่ก่อน; ขยายรัศมีให้ค้นเฉพาะวงนอกที่เพิ่มขึ้น
3. เปลี่ยนหมวดหมู่ต้องเปลี่ยน query signature และห้ามนำ cache ของหมวดปิดกลับมาแสดง
4. ทุกจุดเก็บ source, osm id/geometry, updatedAt, expiresAt และ confidence
5. เรียงด้วยระยะทาง Haversine จากตำแหน่ง GPS ล่าสุดทุกครั้ง
6. GPS เป็นคนละปัญหากับอินเทอร์เน็ต: browser ต้องได้รับสิทธิ์ Location และ production ต้องเป็น HTTPS/secure context

## แหล่งข้อมูลสำหรับต่อยอด national ingest

- OpenStreetMap Thailand / OSM data
- data.go.th: ชุดข้อมูลจุดเสี่ยงอุบัติเหตุทางถนน
- data.go.th: ชุดข้อมูลจุดตั้งด่านทางจราจร / จุดตรวจจุดสกัด
- หน่วยงานทางหลวง/ทางหลวงชนบทและ feed เหตุการณ์/ปิดถนนที่มี API หรือไฟล์เผยแพร่
- รายงานจากผู้ขับขี่ผ่าน Netlify Blobs สำหรับเหตุการณ์ชั่วคราว

## ข้อจำกัดที่ต้องประกาศใน UI

ระบบนี้เป็นระบบช่วยเตือน ไม่ใช่ฐานข้อมูลทางราชการและไม่ควรรับประกันว่าจุดทุกชนิดจะถูกค้นพบครบ 100%. สำหรับเหตุฉุกเฉิน/คำสั่งปิดถนน/อุบัติเหตุจริง ให้ยึดประกาศและป้ายจราจรในพื้นที่เป็นหลัก
